# Lunaris

## Cómo abrir y correr esto

1. Descomprime esta carpeta y ábrela en Visual Studio Code.
2. Abre una terminal en VS Code (Terminal > New Terminal) y ejecuta:
   ```
   npm install
   npm run dev
   ```
3. Abre en el navegador la URL que muestre la terminal (normalmente http://localhost:5173).

Requiere tener Node.js instalado (v18 o superior). Descárgalo de https://nodejs.org si no lo tienes.

Todo el código de la app vive en `src/App.jsx`. Ver `Lunaris-Arquitectura.md` (en el mismo chat) para el detalle de decisiones y alcance de cada módulo.
